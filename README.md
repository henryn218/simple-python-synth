# simple-python-synth

This simple synthesiser allows you to play sine or square wave tones using your computer keyboard.

The z key plays the note C4 (261.63 Hz), otherwise known as middle C.

The keys are laid out like a piano keyboard: the keys s x d c v g b h n j m , l . ; / each play a semitone step up from the previous note.

Press the Esc key to exit. Note you won't be able to use your keyboard while the synthesiser is running.
